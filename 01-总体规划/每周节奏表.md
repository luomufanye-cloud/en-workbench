# 每周节奏表（每天 1.5~2 小时）

- **日期**：2026-08-15
- **摘要**：固定每周节奏，减少"今天学什么"的决策消耗。每天 = 碎片输入 + 90分钟主块 + 5分钟日志。

## 一天的结构

| 时段 | 时长 | 内容 |
|---|---|---|
| 碎片时间（通勤/排队/睡前） | 20-30min | Anki 复习单词 / 泛听英语播客（不计入主块，听个响也行） |
| 主块 ① | 25min | 词汇：新词 + 复习（雷打不动，每天第一件事） |
| 主块 ② | 40min | 当日专项（见下表，按星期轮换） |
| 主块 ③ | 25min | 输出练习：口语 或 写作（与专项错开，口语日用 AI 陪练） |
| 收尾 | 5min | 填写 `02-每日模板/每日学习日志.md` |

## 一周安排

| 星期 | 专项（40min） | 输出（25min） | 说明 |
|---|---|---|---|
| 周一 | 阅读：六级仔细阅读 2 篇，逐题分析 | 口语 15min Shadowing | 一周从最安静的阅读开始 |
| 周二 | 听力：精听 1 篇六级真题 | 口语 15min 跟读+复述 | 精听方法见六级手册 |
| 周三 | 写作：1 篇作文或翻译，AI 批改 | 重写批改后的作文 | 输出与专项合一，今天口语只做 5min 热身 |
| 周四 | 听力：精听 1 篇 + 复习周二错题 | 口语 25min AI 话题陪练 | |
| 周五 | 阅读：长篇阅读/匹配题 + 词汇整理 | 口语 15min 话题自述（录音） | 录音存档，月底对比 |
| 周六 | **口语专项日**：40min 话题训练 | 雅思 Part 2 卡片练习 25min | 阶段2起加入雅思内容 |
| 周日 | **模考/复盘日**：阶段1做单科小测，阶段2-3做整套模考 | 复盘+更新进度追踪表 | 也是补卡日：缺的任务今天补 |

## 弹性规则

- **最低完成线（再忙也要做）**：词汇复习 15min + 口语 15min。保住这两样，进度就不会崩。
- 某天实在没空 → 当天任务标记为「欠账」，周日上午补。
- 状态好可以加量：优先加「精听」和「口语陪练」，这两项边际收益最高。
- 设计专业大作业/答辩周：切换到最低完成线，路线图上顺延一周，不要有心理负担。

## 口语为什么每天都有

口语是三者并行里最容易被砍、但提升最依赖频率的一项。每天 15-25 分钟小额高频，远胜周末一次 2 小时。且口语素材（自我介绍、专业介绍、观点表达）在六级口语、雅思口语、未来面试中**完全通用**，是性价比最高的投资。
