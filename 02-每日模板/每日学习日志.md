# 每日学习日志（模板 + 当月记录）

- **日期**：2026-08-15 创建
- **摘要**：每天 5 分钟填写。用途不是记账，是让进步可见、让断档可追。

## 使用方法

1. 每天学完，复制下面的「单日模板」粘贴到「当月记录」区，填日期。
2. 打钩只花 2 分钟；「今日一句复盘」必须写，一句话即可。
3. 每周日把这周的日志过一遍，更新 `07-追踪/进度追踪表.md`。

## 单日模板（复制用）

```markdown
### 2026-MM-DD 星期X

- [ ] 词汇：新学 __ 个 / 复习 __ 个
- [ ] 专项（今日是：阅读/听力/写作/口语）：内容______ 用时 __min
- [ ] 输出：口语 __min（材料：____）/ 写作：____
- [ ] 碎片泛听 __min
- 状态评分（1-5）：__
- 今日一句复盘：
- 明日重点：
```

## 当月记录（2026年8月）

## 复盘提示词（可选）

每周日可以把本周日志粘给 AI，用这个提示词：

```
你是我的英语学习教练。这是我本周的学习日志，请：
1. 指出我执行中的问题（断档、偏科、量不足）
2. 根据我的目标（12月六级500+，明年雅思6.5）给出下周调整建议
3. 用一句话给我点实际的鼓励（不要空洞的加油）

【粘贴本周日志】
```
