# 英语学习工作台 · 总览

- **日期**：2026-08-15
- **使用者**：环境艺术设计大四学生（四级已过，同步学习 AI 能力）
- **目标**：2026年12月六级 500+ → 2027年春季雅思 6.5+，口语达到可流利日常/学术交流

## 摘要

本工作台以「六级为主线、雅思为延伸、口语为日常」的逻辑组织：六级与雅思共享词汇和语感化地基，口语用每天 20 分钟输出练习带起来，AI 工具（你正在学的能力）充当口语陪练、作文批改和单词考官。每天投入 1.5~2 小时，每周一个闭环。

## 设计逻辑（为什么这样搭）

1. **一条主线**：六级是最近的可验证里程碑（12月中旬考试），它的词汇、阅读、听力训练 70% 可直接迁移到雅思。
2. **两项通用资产**：词汇量 + 语感（听力）。这两项不区分六级/雅思，全程都在积累。
3. **每天三个动作**：输入（词汇/阅读/听力）→ 输出（口语/写作）→ 复盘（日志/错题）。输出倒逼输入，避免"学了说不出"。
4. **每周一个闭环**：6 天分项训练 + 周日模考/复盘，用分数和打卡记录验证进步。
5. **AI 是放大器**：口语陪练、作文精批、单词抽测全部可用 AI 完成（见 `05-口语/AI陪练提示词.md`），把 AI 学习能力直接用在英语上。
6. **专业加成**：口语话题优先准备「自我介绍 / 我的设计专业 / AI 与设计的未来」，一份准备同时服务六级口语、雅思口语和未来的面试/作品集展示。

## 如何开始（今天就做这 3 件事）

1. **双击打开 `index.html`**（网页版工作台）：在「⚙️ 设置」里核对考试日期，AI 对话需要的话填自己的 API Key（只存浏览器本地）。
2. 完成「阶段0·起跑周」自测：限时做一套六级真题，分数记到网页版「📊 数据」页（或 `07-追踪/进度追踪表.md`）。
3. 明天起每天在网页版「📌 今日」打卡，晚上写一句复盘。

> 网页版（index.html）负责日常打卡和数据可视化，Markdown 文档负责方法论和计划细节，两者数据互通靠手动同步（每周日复盘时对照一次即可）。

## 使用原则

- **不断档比学得多重要**：每天最低完成「词汇 25min + 口语 15min」，状态好再补专项。
- **所有产出留痕**：作文、口语录音、错题都归档进 `07-追踪/`，月底回看即是动力。
- **每 4 周回顾一次路线图**：进度落后就砍任务量，不要砍口语。
